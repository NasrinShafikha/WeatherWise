# WeatherWise

Your everyday weather companion.

## About
WeatherWise is a full-stack weather application developed for the PM Accelerator AI Engineer Intern Technical Assessment.

## Features
- Search weather by city
- Detect current location
- View current weather and a 5-day forecast
- Search weather by date range
- YouTube weather video search
- Google Maps location link
- Save, edit, view, and delete weather records
- SQLite database storage
- Export data as CSV, JSON, XML, PDF, and Markdown
- Responsive frontend

## Technology Stack
- Frontend: React, Vite, CSS
- Backend: Python, FastAPI
- Database: SQLite, SQLAlchemy
- Weather API: Open-Meteo
- Video API: YouTube Data API v3

## Run Locally

### Backend
cd backend
pip install -r requirements.txt
uvicorn main:app --reload

### Frontend
cd frontend
npm install
npm run dev
